Lottie, compiled to native browser animations.

lightie turns Lottie JSON into DOM nodes and Web Animations API keyframes ahead of time. The browser plays them on the compositor, so your animations keep moving while the main thread is busy, with a 3.2 kB runtime instead of a 76 kB one.

How it works

        

          

            
Compile

            

              At build time the compiler flattens precomp time, turns every keyframe segment into an exact
              cubic-bezier(), and writes a compact scene. It also reports anything it cannot reproduce.
            

          

          

            
Composite

            

              The player builds the DOM once and calls element.animate(). Transforms and opacity run on the
              compositor thread; colour changes become cross-fades of opaque copies, so they do too.
            

          

          

            
Worker canvas

            

              Geometry that changes over time (stroke width, trim paths, shape morphing) is drawn by one shared worker
              through OffscreenCanvas, from the same keyframes and the same clock.
            

          

          

            
Fallback

            

              Expressions, text layers and effects are reported by the compiler. With a fallback configured, lottie-web is
              loaded only for those files; everything else never downloads it.

Get started

        

          

            
Compile at build time with Vite

            
// vite.config.ts
import lightie from 'lightie/vite';
export default { plugins: [lightie()] };

// app.tsx
import { Lightie } from 'lightie/react';
import loader from './loader.json?lightie';

<Lightie animation={loader} autoplay loop />

          

          

            
Or use the CLI and the Web Component

            
npx lightie compile loader.json -o loader.lightie.json
npx lightie check animations/*.json

<script type="module">
  import 'lightie/element';
</script>
<lightie-player src="/loader.lightie.json" autoplay loop>
</lightie-player>
